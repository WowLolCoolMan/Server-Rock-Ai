# UI reference implementation progress

The full reference set and owner requirements are documented in [`UI_REFERENCE_GUIDE.md`](UI_REFERENCE_GUIDE.md). This page tracks shipped behavior against that guide so developers and coding agents can continue the work without treating a visual resemblance as feature completion.

## Current slice

| Area | Implemented behavior | Evidence | Remaining work |
|---|---|---|---|
| GitHub repository entry | The sidebar opens the GitHub workspace panel directly from both ChatBot and Coding Agent modes, including when disconnected. The disconnected panel keeps the client ID, keyring status, and sign-in action visible; repository search, manual repository entry, clone path, and clone action appear after GitHub access is available. | Isolated Windows App SDK smoke opened the workspace from the sidebar without a saved connection; the accessibility tree exposed the connection prompt and no repository/clone controls. The ChatBot and Coding Agent shell visibility paths now share the same GitHub entry. Existing Playwright coverage verifies the legacy shortcut does not redirect to Settings, and native GitHub service tests cover repository and Git workflows. | Verify signed-in, empty-permissions, permission-denied, network-error, and clone-to-project states in an isolated profile. |
| Chat organization | Hover/overflow, right-click, and the keyboard context-menu shortcut open the same menu. Up/down plus Home/End navigate actions; Escape restores focus to the trigger. Rename, pin, unread/read, move to project, archive/restore, and confirmed permanent deletion operate on local chat data. Archived chats remain recoverable. | Playwright: `chat context menu actions rename, pin, move, archive, restore, and delete local chats`; `chat actions support the keyboard context-menu key, arrow navigation, and focus restoration`. Both passed after the keyboard improvement. | Test longer project menus and narrow windows. Share/open-in-new-window remain unimplemented until there are real workflows behind them. |
| Mini & Pets | An account popover exposes show/hide and customization. Original local companion choices persist on this device. Three original pixel-style SVG characters render locally in the mini and picker. The companion can be dragged with a pointer or placed with an explicit keyboard move mode, persists a clamped per-device position, announces movement state, and can be reset from settings. | Playwright verifies all three illustrations load, pointer drag, reload persistence, keyboard movement, reset, and narrow-screen bounds; the pet does not overlap primary controls on chat, images, or the terminal activity view at 1280×720 and 390×844. An isolated Electron live review confirmed Rocky renders, Move/Hide controls work, right-arrow movement responds, and Escape exits move mode. The Windows x64 unpacked package contains all three SVGs. | The current companion is an in-window card, not an always-on-top desktop companion. Decide whether to pursue that stronger reference parity; tune default placement or interaction states from user feedback. |
| Native Markdown code blocks | Code blocks keep source indentation and long lines scroll horizontally instead of wrapping; code and copy controls have screen-reader names, with the copy action's purpose described. | Native solution built successfully for shared Skia desktop and Windows App SDK targets after this change. Syntax highlighting remains open. |
| Native responsive navigation | The fixed desktop sidebar changes to an overlay drawer with a hamburger toggle, backdrop close action, Escape close action, and focus return. The compact transition starts below 1,320 effective pixels so a 1280px snapped window uses the drawer. The companion card docks below the header in compact mode without covering the welcome panel or composer. | Desktop and isolated Windows targets build with zero warnings and errors. Live compact review confirmed the companion no longer covers the connection control or welcome/composer area. | Verify drawer open/close, Ctrl+Shift+E activation, Escape, backdrop, focus return, and navigation selection on Windows and Linux/Skia at a compact viewport. |
| Native model connection handoff | Settings keeps a stable Save/Cancel model-connection dialog; the native Models navigation opens AI SuperMarket directly. | Core and native builds pass. A live Settings → Browse models experiment exposed an unhandled Uno `Win32UIAutomation` accessibility crash when opening a second ContentDialog, so that unsafe shortcut was removed instead of shipping a process-terminating path. | Design a structural, single-dialog model-library handoff and verify it live before reintroducing a secondary action. |
| GitHub app updates | Stable and beta releases are read from the app repository's public GitHub Releases API. The UI reports no-release/network states, compatible installer name/size, GitHub's SHA-256 digest, and opens the exact release page for a user-directed download. The old external-service updater and CI configuration are removed. | `npm test` passed: 90 Playwright cases plus 3 direct updater unit cases. `npm run check:syntax`, `npm run check:hygiene`, `npm run audit:ui` (wide, desktop, tablet, mobile, small-mobile), and `npm run audit:electron` passed. GitHub API behavior has mocked tests for stable/beta selection, digest/asset validation, redirect rejection, and no release. A live GitHub API check returned the expected no-stable-release state. | This only checks the published GitHub feed and opens the release page; it does not download/install automatically. There are no published releases to verify yet. The release workflow still needs an end-to-end asset naming check when the first release is created. |
| Electron-to-native chat migration | Electron Settings offers “Move chats to the native app,” exporting saved chats only with format/version metadata and a 25 MiB cap; provider credentials, project folders, and account connections are excluded. Native import previews the selected chats, preserves archived and fork/branch metadata, leaves the source file untouched, skips/reassigns duplicates safely, and does not import Electron project paths or credentials. The native Recents UI exposes an expandable Archived group with Archive/Restore actions, branch navigation, and contextual Fork from here. | Playwright verifies the real export UI path excludes secrets and private project paths. Core fixture checks cover the Electron envelope, bounded parsing, no-write preview, metadata round-trip, branch persistence, fork independence, and idempotent re-import. Isolated Windows App SDK smoke used `SRAI_CONVERSATIONS_PATH` with a temporary profile: an archived chat appeared under Archived; Restore moved it to Recents; Archive moved it back; after restart it remained archived. A second isolated smoke verified Main plus three alternate branches, Previous/Next boundary states, and return to Main with original content intact. A third isolated smoke opened the overflow menu, activated accessible “Fork from here,” created an independent fork with the selected timeline, and left the source available. Desktop and Windows targets built with 0 warnings/errors. Keyboard focus transfer, narrow-layout behavior, Linux/Skia interaction, and a real Electron profile handoff remain acceptance work. | Run an interactive handoff from a real Electron profile through native import on Windows and Linux; verify confirmation, cancel, retained chat history after restart, keyboard focus/narrow layout, and contextual Fork from here on both native targets. |
