# Pull request / architecture decision templates

## PR template
```
Title:
Requirement IDs:
Baseline commit / branch:
User journey before / after:
Files and contracts touched:
Data/schema/permissions change:
Source/license provenance:
Actual build/tests (commands + observed output):
Windows: tested / not tested + exact env:
Linux: tested / not tested + exact env:
Keyboard/AT/overlay/narrow window evidence:
Screenshots/recordings:
Rollback/undo:
Known limitations and follow-up:
Reviewer:
```

## ADR template
```
ADR ID, title, author, status, date of decision:
Problem and existing implementation:
Options considered:
Constraints and owner decisions:
Measured prototype results on Win/Linux:
Security/data/compatibility costs:
Decision with rationale:
Alternative rejection reasons:
Rollback/exit criteria:
Evidence links and explicit owner approval (if architecture migration):
```

No framework migration without explicit user approval. Do not treat draft ADR as approval.
