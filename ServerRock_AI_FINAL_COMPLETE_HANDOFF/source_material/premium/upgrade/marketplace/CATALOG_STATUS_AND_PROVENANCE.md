# Candidate catalog disclaimer and source evidence

Historical `catalog_250.json` from `Server_Rock_AI_Elite_Skill_Marketplace_250.zip` was preserved unchanged as `catalog_250_candidates.json`; earlier research includes directory-listing evidence circa 2026-11-08 and `requires_review=true` on candidate entries. The file includes 250 distinct catalog rows, NOT 250 vetted, cross-platform installable skill packages.

Do not assume a GitHub folder is a skill, that its license permits copying, or that its instructions are safe/executable. Prior `foundations_50.json` is a source/tools research index, not installed skills. Original example skills and marketplace code are archived under `upgrade/marketplace/historical_samples/`; treat as ideas/fixtures, never runnable production update services.

To graduate an entry to Verified Installable: check URL and repository ownership today; inspect license at exact commit; fetch/read complete manifest and dependencies; validate supported Windows/Linux paths; vet external network/permissions, prompt-injection risk and payload; ensure safe atomic install/update/uninstall; record test evidence; produce version-pinned manifest. Badge status must come from verified registry, not catalog text. Preserve attribution and user consent.

Data fields appended in curated registry should include `reviewedAtUtc`, `reviewer`, `sourceCommitSha`, `contentSha256`, `licenseEvidenceUrl`, `securityReviewId`, `windowsTestId`, `linuxTestId`, `trustStatus`, `installable`, `appCompatible`, `lastSeenAtUtc`. Evidence that expired or upstream changed resets status to `needs_review`.
