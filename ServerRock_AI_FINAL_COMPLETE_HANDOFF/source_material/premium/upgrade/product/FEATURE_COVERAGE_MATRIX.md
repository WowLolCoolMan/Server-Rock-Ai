# Capability map: every major user-facing system

| Product surface | Minimum complete vertical slice | Deep/premium version |
|---|---|---|
| Home | Resume recent sessions/projects, connect missing model, one-click create | Pinned sections, actionable pending approvals, personalized quick actions, recent runs |
| Chat | Streaming, stop, history, attachments, model picker, retry, branches | Folders, search, context inspector, inline artifacts, privacy scope, forks, export |
| Projects | Named roots, browse files, Git state, active chats | Multi-root, worktree manager, saved panel layouts, file search, task index |
| Coding workspace | Chat + file edits preview + terminal + test status | Tabbed editor, partial diff accept, approvals inbox, multi-pane, queued agents |
| Agent Center | Start/cancel, tool timeline, state, error | Parallel lanes, dependencies, resumption, budget/quota dashboards, supervisor |
| Models | Local discovery + cloud connection states | Capability matrix, local hardware fit, downloads, measured perf, routing profiles |
| Workflows | Saved linear templates, run history, step review | DAG builder, reusable subflows, approvals, triggers, simulation, versioning |
| Skills | Browse/inspect, explicit install/remove, enable per project | Source verification, dependencies, updates, rollback, health, routing explanation |
| MCP/Connections | Add/disable verified MCP and provider credentials | Permission scoping, health, tool discovery, logs, reconnect, revocation |
| Activity/Notifications | Searchable task timeline, approvals/errors | Filtered inbox, unread, per-project, system health and retention controls |
| Settings | Grouped search, theme, model/provider, privacy, paths | Profiles, shortcuts, diagnostics, imports/backups, sync opt-in, accessibility |
| Updater | Verified check/download with confirmation | Signed channels, rollback UI, migration preview, post-upgrade health |
| Pets (existing) | Optional hide/show with no input/focus interference | Accessible settings, sprites, idle modes and efficient transparency |

No surface is 'done' until controls actually work, data exists, and adverse states are verified.
