# Competitive differentiation gates — evidence over claims

## Strategic advantage hypotheses
1. One UI for multiple cloud/local model providers, with privacy routing and transparent failover.
2. User-owned skills with manifest-driven install/update/rollback/remove and clear dependencies.
3. Predictable operations: explicit state, preflight, preview, approval, execution, verification and recovery.
4. Context inspector and local-first memory control; clear indication of what is shared remotely.
5. First-class Windows/Linux parity and approachable setup.
6. Advanced coding workflow: tests, diffs, agent activity, workspace isolation and evidence.
7. Performance budgets and graceful offline operation.

## Avoid false comparisons
Codex and Claude desktop already have strong capabilities. Never claim feature uniqueness or superiority without current evidence. Benchmark against equivalent versions and workflows; publish limitations.

## Hard acceptance metrics (targets, not measured facts)
- >=90% of new testers finish a useful first task within five minutes after prerequisite model availability.
- >=95% successful skill install/update/remove on supported platforms in test matrix.
- 0 unapproved consequential file changes in controlled test suite.
- 100% of tool runs produce terminal status or recoverable pending state after crash/restart tests.
- >=90% task recovery success in intentionally injected recoverable faults.
- 100% of tested remote-data transfers show provider and data scope before consent where required.
- 0 knowingly misleading success notifications in test suite.
- All P0 accessibility, packaging, signing and uninstall gates pass before public release.

## Benchmark tasks
- First install and connect an available local model.
- Add a remote provider and inspect the data route.
- Install a skill from a pinned revision, use it, update it and remove it.
- Run a coding task with planned changes, approval, tests and rollback.
- Switch providers mid-workflow and verify compatibility re-evaluation.
- Cancel during download, tool execution and restart.
- Work offline and recover after network return.
- Export, import and search chat history without losing branches.
- Reinstall or upgrade without losing user data.
- Complete all tasks with keyboard only on Windows and Linux.

Collect task success, time, crashes, latency, cost, perceived control and confidence. Use matched tasks against alternatives; do not cherry-pick.
