# Competitive comparison: evidence-based scorecard

Compare representative workflows against contemporary Codex desktop, Claude desktop, and relevant open-source AI clients; do not claim guaranteed superiority. Record app versions, hardware, model, network, task inputs and evaluator. Score 0–5 with notes:
- First useful task success and setup friction
- Code editing accuracy, tests and diff review
- Agent run transparency and recoverability
- Local/cloud model choice and privacy clarity
- Skill install/update/remove reliability
- MCP setup and permission visibility
- UI navigation, density, consistency and keyboard accessibility
- Chat history portability and discoverability
- Diagnostics quality and self-service troubleshooting
- Windows/Linux parity, performance, packaging and upgrade
- Cost/usage clarity and resource control
- Error recovery and offline operation

Require user tests, not only agent-generated screenshots. Report tradeoffs and missing capabilities; do not cherry-pick.
