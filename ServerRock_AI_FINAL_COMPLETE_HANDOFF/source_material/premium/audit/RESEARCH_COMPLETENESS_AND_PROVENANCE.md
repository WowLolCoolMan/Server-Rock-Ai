# Evidence limitations and inventory completeness

This pack combines the latest available 68-file architecture masterplan with earlier locally available ZIPs. Prior chat context and retrievable summaries were reviewed, but this is NOT a full verbatim export of all ChatGPT chats. The user should treat historical assistant reports as leads, not independently verified source evidence.

The existing research includes a `top_50_skills` candidate list and smaller MCP/repository shortlists. It does **not** substantiate a verified 50+50 audited, installable skill/MCP catalog, nor a vetted 250–500 skill marketplace. These are catalog acquisition and verification goals.

Candidate repository URLs are discovery leads, not endorsement or license approval. Before copying any code verify current URL, LICENSE, exact commit, subcomponent notices, compatibility, security, build and tests. Official OpenAI/Anthropic desktop source must not be assumed open-source. Odysseus remains ideas-only.

This ZIP contains plans, specifications, lists and acceptance criteria. It does not contain or claim to contain the full third-party source repositories, 250 installed skills, 50 working MCP servers, a compiled app, a completed UI rewrite, or a runtime audit of Server Rock HEAD.
