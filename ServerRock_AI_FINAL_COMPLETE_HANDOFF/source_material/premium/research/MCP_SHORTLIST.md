# MCP shortlist for Server Rock AI

Prioritize GitHub, Playwright, Filesystem, Context7 and Docker MCP Gateway. Other entries are optional and should be enabled only for matching tasks. Some links point to reference collections, not current standalone installable packages.

1. **Filesystem** — Scoped local file operations. https://github.com/modelcontextprotocol/servers
2. **GitHub** — Repositories, issues, pull requests. https://github.com/github/github-mcp-server
3. **Playwright** — Browser interaction and UI testing. https://github.com/microsoft/playwright-mcp
4. **Docker gateway** — Containerized MCP orchestration. https://github.com/docker/mcp-gateway
5. **Context7** — Library documentation. https://github.com/upstash/context7
6. **Memory** — Knowledge persistence reference. https://github.com/modelcontextprotocol/servers
7. **Fetch** — Web retrieval reference. https://github.com/modelcontextprotocol/servers
8. **Git** — Git repository operations reference. https://github.com/modelcontextprotocol/servers
9. **SQLite** — SQLite access reference. https://github.com/modelcontextprotocol/servers
10. **PostgreSQL** — Database schema and queries reference. https://github.com/modelcontextprotocol/servers
11. **Sequential thinking** — Structured reasoning reference. https://github.com/modelcontextprotocol/servers
12. **Sentry** — Issue and error investigation. https://github.com/getsentry/sentry-mcp
13. **Cloudflare** — Cloudflare infrastructure. https://github.com/cloudflare/mcp-server-cloudflare
14. **Kubernetes** — Kubernetes operations. https://github.com/containers/kubernetes-mcp-server
15. **Unity** — Unity editor automation. https://github.com/CoplayDev/unity-mcp

## Marketplace requirements
- Validate repository, license, release, checksum and server launch command.
- Show required credentials, filesystem roots and permission changes before installation.
- Discover tools dynamically, namespace collisions, and expose only relevant tools per task.
- Support health checks, cancellation, timeout, logs, pinned versions, update indicators and rollback.
