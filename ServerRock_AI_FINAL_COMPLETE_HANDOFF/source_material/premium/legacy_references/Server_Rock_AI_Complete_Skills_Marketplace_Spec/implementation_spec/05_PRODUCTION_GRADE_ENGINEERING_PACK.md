Purpose: produce deliberate, idiomatic, verifiable software across websites, desktop apps, Minecraft mods, Unity games and libraries; not conceal provenance or fabricate human authorship.

- Architecture and project conventions
- Idiomatic code and anti-boilerplate review
- Dependency/version/API validation
- Test-driven implementation and systematic debugging
- Security/static analysis
- Runtime observability and failure reproduction
- UI/UX art direction and anti-generic design
- Browser/visual regression testing
- Documentation and release verification
