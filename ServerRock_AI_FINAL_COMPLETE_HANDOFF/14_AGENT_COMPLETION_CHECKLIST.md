# Definition of done — tick only with linked evidence

- [ ] Have inspected *current* repository files and preserved dirty/untracked work on Windows and Linux.
- [ ] Have recorded provenance for changes, dependencies, licensed materials and owner approvals.
- [ ] Have a native Uno/XAML shell with stable routed navigation, dark/light tokens, persisted layout, command palette, consistent shortcuts and accessible native menus.
- [ ] Every implemented route has verified empty/loading/error/offline/permission/working states, truthful actions, hover/focus/keyboard semantics and no hidden clicks.
- [ ] Overlay/pet/drawer/modal focus and hit testing verified at wide and narrow viewports on both platforms.
- [ ] Conversations stream, cancel, persist and branch correctly; attachments stay scoped to intended provider; local/cloud identity is always honest.
- [ ] Projects open real folders/repos and preserve changes; file explorer/diff/terminal/Git review are usable, with safe permissions, undo and conflict detection.
- [ ] Agent task engine has durable IDs/events, visibility during navigation, safe cancellation, external side-effect reconciliation, reviewable tool actions, parallel isolation and tests.
- [ ] Provider adapters report capabilities and failures; no silent cloud transition; local hardware limits and model download/installation errors are handled.
- [ ] Workflow editor and runner either execute tested DAGs with real artifacts/approval or are clearly experimental and not falsely advertised.
- [ ] Marketplace distinguishes candidate/reviewed/installed/enabled/executable; license, dependencies, provenance and update/rollback were checked. No claim that all 250 candidates are verified.
- [ ] MCP/ACP/Codex connections state exact compatible features and real health, with scoped authorization, credential storage and revocation.
- [ ] Settings validate before save; history/data migrations are backward compatible and recoverable; diagnostics are redacted; updates are signed and verified.
- [ ] Accessibility, Windows & Linux native interaction, installer upgrade/uninstall/rollback, secrets, offline operation and recovery are tested on **exact** release artifacts.
- [ ] Final handoff report includes all decisions, changed files, commands/outcomes, screenshots, supported OSes, release artifacts, unresolved blockers and rollback procedures.

**No false-green rule:** If evidence is missing, leave unchecked and mark `unverified` or `blocked`. The pack documents the target; it does not indicate these tasks have been done.
